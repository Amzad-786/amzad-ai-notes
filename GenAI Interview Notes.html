1.1

LLM kya hota hai?

LLM ek AI program hota hai jo bahut saare text data (books, websites, articles, etc.) par train kiya gaya hota hai. Iski madad se wo insaano ki tarah language samajh sakta hai aur naya text generate kar sakta hai.

Examples
  • ChatGPT (OpenAI ka)
  • Gemini (Google ka)
  • Claude (Anthropic ka)
  • Llama (Meta ka)

Basic understanding level par janna hai.

Important

1.3

Tokens aur tokenization

LLM poore sentence ko ek single unit ki tarah nahi samajhta. Text ko chhote-chhote pieces mein tod diya jata hai. In pieces ko tokens kehte hain. Tokenization = text ko tokens mein convert karne ka process.

Interview line

Tokenization is the process of breaking text into smaller units called tokens. These tokens can be words, parts of words, punctuation, or other text fragments. Each token is mapped to a numerical token ID, which is then processed by the LLM. Tokenization is important because token count affects context limits, processing, and API cost.

LLM ek request mein maximum kitne tokens ko process/consider kar sakta hai.

Example
Agar model ka context window 128K tokens hai, to prompt + conversation + documents + output ko us limit ke andar rehna hota hai.
Interview line

Context window is the maximum amount of token-based information an LLM can handle in a single context.

1.6

Top-K aur Top-P

Ye dono decide karte hain ki model next token choose karte waqt kitne possible tokens consider karega.

Top-KTop-P
DefinitionModel sirf K highest-probability tokens mein se next token choose karta hai.Model tokens ko unki probability ke basis par tab tak consider karta hai jab tak cumulative probability P reach nahi ho jati.
ExampleTop-K = 5, model sirf top 5 candidates consider karega.Top-P = 0.9, model un highest-probability tokens ko consider karega jinki combined probability approximately 90% tak pahunchti hai.
Interview line

Top-K limits the number of candidate tokens, while Top-P limits candidates based on cumulative probability.

It is a technique where we retrieve relevant information from an external knowledge base and provide that information as context to an LLM before generating the answer.
